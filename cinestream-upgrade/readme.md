# 🎬 CINE-STREAM (Next.js 15 Edition)

A high-performance movie discovery application built with **Next.js 15**, leveraging Server-Side Rendering (SSR) for optimal SEO and speed.

## 🚀 The Mission
The goal of this project was to migrate a standard Client-Side Rendered (CSR) React app into a modern SSR environment. By shifting data fetching to the server, we've improved initial load times and ensured that search engines can fully index our movie content.

## 🛠️ Technical Stack
* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript / JavaScript
* **Styling:** Tailwind CSS
* **API:** [The Movie Database (TMDB)](https://www.themoviedb.org/)
* **Interactivity:** React Client Components

## ✨ Features
* **Server-Side Rendering (SSR):** Popular movies are fetched on the server, reducing the JavaScript bundle sent to the client.
* **Dynamic UI:** Responsive grid layout built with Tailwind CSS.
* **Favorites List:** Users can save movies to their local library, persisted via `localStorage`.
* **Optimized Images:** Configured remote patterns for secure and fast image loading from TMDB servers.
* **Clean Search:** A minimalist, top-aligned search interface for quick discovery.
