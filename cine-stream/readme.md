🎬 Cine-Stream (Movie Explorer)<br>
Cine-Stream is a high-performance "Netflix-lite" movie discovery application. It was built to demonstrate advanced React patterns, specifically focusing on Infinite Scroll, API Debouncing, and UI/UX Optimization for handling large datasets.<br>

🚀 Key Features<br>
1.Infinite Scroll: Utilizes the Intersection Observer API to detect when the user reaches the end of the list and automatically fetches the next page of movies, providing a seamless browsing experience.<br>

2.Search Debouncing: Implements a 500ms delay on search inputs to prevent unnecessary API calls and optimize network traffic while the user is typing.<br>

3.Persistent Favorites: Allows users to "Heart" movies, saving them to LocalStorage so their favorites list remains intact even after a page refresh.<br>

4.Responsive Grid: A modern, mobile-first CSS Grid layout built with Tailwind CSS, featuring hover effects and smooth transitions.<br>

🛠️ Tech Stack<br>
1.Frontend: React (Vite)<br>

2.Styling: Tailwind CSS<br>

3.Icons: Lucide React<br>

4.API: TMDB (The Movie Database)<br>

5.Deployment: GitHub Pages / Vercel<br>

📖 What I Learned<br>
This project was a deep dive into performance optimization. I learned how to:<br>

1.Manage complex state transitions when switching between "Popular" and "Search" results.<br>

2.Configure PostCSS bridges to handle Tailwind v4 architecture.<br>

3.Optimize browser rendering by using refs and callbacks with the Intersection Observer.<br>
