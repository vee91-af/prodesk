# 📚 Storybook Design System - Cine-Stream

This project demonstrates a professional frontend workflow by building UI components in isolation using **Storybook**. By decoupling components from the main application, we ensure reusability, visual consistency, and easier testing.

## 🚀 Live Demo
**View the Design System:** storybook-static-ifda5x9q0-vaishnavis-projects-4a082ada.vercel.app

---

## 🛠️ Levels Achieved

### ✅ Level 1: Setup & Isolation
- Installed and configured Storybook with **React + Vite**.
- Created a library of 3 core components: `Button`, `Input Field`, and `Product Card`.
- Components are viewable in an isolated UI dashboard.

### ✅ Level 2: Variants & Theming
- **Args (Props):** Configured components to accept dynamic properties.
- **Toggles:** Added controls to switch between `Primary`, `Secondary`, and `Disabled` states.
- **Dark/Light Mode:** Integrated background toggles to test visual consistency across themes.

### ✅ Level 3: Advanced Deployment
- **Static Build:** Generated a production-ready static build of the Storybook library.
- **Deployment:** Hosted the design system as a standalone web application.
