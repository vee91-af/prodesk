Kanban Task Board Pro<br>
A modern, responsive Kanban Task Management application built with React and Tailwind CSS. This project features a clean UI for managing tasks across different stages of a workflow.

🚀 Features<br>
Drag and Drop Interface: Intuitive task management (if implemented).<br>

Responsive Design: Fully functional on desktop and mobile.<br>

Dark Mode Support: Styled with Tailwind CSS for a modern look.<br>

Task Categorization: Move tasks between "To Do", "In Progress", and "Done" columns.<br>

🛠️ Tech Stack<br>
Frontend: React.js with Vite<br>

Styling: Tailwind CSS<br>

Icons/Assets: Lucid React or similar libraries.<br>
